# LoanFlow

Учебный кредитный конвейер для потребительских кредитов: от заявки до договора и графика платежей.

## Как запустить документацию

Нужен Python 3.12 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-docs.txt
mkdocs serve
```

Сайт откроется по адресу <http://127.0.0.1:8000>. Страницы обновляются автоматически при сохранении файлов в `docs/`.

Собрать статический сайт в папку `site/`:

```bash
mkdocs build --strict
```
