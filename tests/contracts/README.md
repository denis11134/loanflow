`cases.json` — сохранённые тела запросов и ответов, позитивные и негативные примеры.
При наличии `operation` тест берёт схему соответствующего HTTP-ответа, включая `oneOf`.
Без `operation` проверяется указанный компонент. Для `ContactContract` проверяется вложенный объект ответа КЦ.
`valid` означает ожидаемую допустимость по уже существующим документам, а не текущий результат схемы.

`issue` сохраняет ссылку на исходное замечание API-01–API-06. Все примеры проверяются на общих условиях с исходным значением `valid`.

`behavioral-cases.json` — отдельные контрпримеры для будущих сервисных проверок:
схема не заменяет арифметику отчёта, корреляцию идентификаторов или чтение истории БД.
Они не объявлены проходящими тестами несуществующего сервиса.

Структуру OpenAPI проверяет другой тест с официальной схемой. Успешная проверка структуры
не означает корректность примеров ответов или реализации API.
