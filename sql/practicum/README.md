# Запуск существующих решений

`queries.sql` перенесён без изменения из найденного ранее файла
`/tmp/loanflow-practicum-review.qYpsUF57/queries.sql`. Эта запись объясняет происхождение;
при запуске временный исходник не используется. Новые аналитические запросы не добавлялись.
Пять решений сверены с требованиями заданий и контрольными таблицами главы 2.4.

```bash
.venv/bin/python -m pytest -q tests/test_database.py
```

Тест создаёт собственный временный PostgreSQL 18, применяет DDL, штатный SQL-тест и фикстуры,
затем выполняет пять запросов. Для запроса №1 подставляет четыре уже заданных контрольных
`customer_id`. Ожидания читает прямо из авторских таблиц `docs/04-data/2.4-sql-practicum.md`.
Сравниваются имена столбцов, количество, порядок строк и значения, включая `NULL`,
точные десятичные числа и моменты времени. Кластер останавливается в `finally`.
Отдельный тест проверяет остановку при намеренном исключении.
