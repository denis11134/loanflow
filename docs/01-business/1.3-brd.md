## 1. Бизнес-цели и проблематика
**AS-IS:** Процесс работает на legacy-решении (лицензия до 31.12.2027). TTM изменений политики занимает 2–3 месяца. Регуляторные требования (период охлаждения, самозапрет) поддерживаются ручными процессами. 

**TO-BE (Цели проекта):**
1. Снижение комплаенс-рисков: 0 нарушений регуляторики по выданным кредитам.
2. Подготовка базы для полного отключения legacy к 31.12.2027.
3. [Цель 2028, вне MVP]: Ускорение TTM до ≤ 2 недель.
4. [Цель 2028, вне MVP]: Снижение стоимости обработки заявки на 30%.

## 2. Границы MVP (Scope)
**Дедлайн:** 1 июля 2027 года.
**Приоритеты:** Сроки (Жестко) > Комплаенс (Жестко) > Фичи (Могут урезаться).

### 2.1. In Scope (Что входит в MVP)
* **Продукт:** Кредит наличными (без залога, без страховок).
* **Аудитория:** Строго зарплатные клиенты банка. (Пенсионеры — под вопросом, TBD).
* **Трафик:** Поэтапная раскатка до 100% мобильного трафика зарплатников.
* **Бизнес-процесс (Полный цикл):**
  * Создание Заявки.
  * Оценка (Decision Engine, каскад проверок 218-ФЗ/115-ФЗ).
  * Формирование Предложения.
  * Подписание (ПЭП).
  * Период охлаждения.
  * Автозачисление на счет.
  * Ручной андеррайтинг (пилотная группа).
* **Каналы:**
  * **Мобильное приложение (МП):** Подача, подписание, отказ, выдача.
  * **Контакт-центр (КЦ):** просмотр статуса. На учебном стенде оператор после идентификации клиента может оформить отказ от получения кредита из `COOLING_OFF`.
  * **Отделения:** Только Read-Only (проверка статуса для исключения двойных заявок).

### 2.2. Out of Scope (Во 2-й релиз)
* Не-зарплатные клиенты (до интеграции с Госуслугами).
* Интернет-банк, форма на сайте.
* Полноценный BRMS-инструмент (в MVP правила пишут разработчики).
* Доработка Legacy для онлайн-синхронизации квот.

## 3. Метрики успеха (KPIs)

Для ссылки на метрику из другого документа используйте «BRD M-NN».

| ID | Метрика | Владелец | AS-IS | Цель MVP |
| :--- | :--- | :--- | :--- | :--- |
| M-01 | **Доля авторешений** | Риски | ~65-70% (по зарплатникам) | Не хуже AS-IS когорты |
| M-02 | **Time-to-Decision (Авто)** | Заказчик | Мед. 40 мин | 90-й перцентиль < 3 мин |
| M-03 | **Time-to-Decision (Ручн)** | Рук. андеррайтинга | 1-2 раб. дня | Тот же раб. день |
| M-04 | **Конверсия в выдачу** | Заказчик | ~18% (в целом) | 25% |

## 4. Стейкхолдеры проекта
* **Бизнес-заказчик:** Сроки, конверсия.
* **Клиент:** UX, соблюдение прав по 353-ФЗ.
* **Риски:** Настройка правил, ПДН, квоты.
* **Юристы и AML:** Комплаенс (353-ФЗ, 218-ФЗ, 115-ФЗ).
* **Руководители КЦ и Отделений:** Нагрузка на операторов/сотрудников.
