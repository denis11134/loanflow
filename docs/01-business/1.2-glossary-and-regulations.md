# Глоссарий и Регуляторика (LoanFlow v2.0)

## 1. Базовые термины и метрики

| Термин | EN (в коде) | Определение | Источник |
| :--- | :--- | :--- | :--- |
| **Кредитный конвейер** | `Loan Origination System (LOS)` | Автоматизированная система полного цикла: от приема заявки до зачисления средств на счет клиента. | Архитектура |
| **Заявка** | `Application` | Запрос клиента на получение кредита с указанием желаемой суммы, срока и перечнем персональных данных. | Предметная область |
| **Отказ банка** | `Bank Reject` | Терминальный статус заявки. Решение банка не выдавать кредит из-за стоп-факторов, негативного скоринга или исчерпания МПЛ. | Предметная область |
| **Отказ клиента** | `Client Cancel` | Терминальный статус заявки. Инициирован клиентом (кнопка «Отказаться») до выдачи кредита, в том числе во время периода охлаждения. | Предметная область |
| **Предложение** | `Offer` | Одобренные банком индивидуальные условия (сумма, ставка, срок, ПСК), доступные клиенту для подписания. | Предметная область |
| **Выдача** | `Issue / Disbursement` | Факт фактического зачисления денежных средств на счет клиента и активация кредитного договора. | Предметная область |
| **Доля авторешений** | `Auto-decision rate` | Доля заявок (в %), по которым система приняла финальное решение (одобрение или отказ) без участия человека. *Цель: 80%*. | Интервью 1.1 |
| **Время до решения** | `Time-to-decision (TTD)` | Время от нажатия клиентом кнопки «Отправить заявку» до вывода решения на экран (исключая период охлаждения). *Цель: < 3 мин для 90% авторешений*. | Интервью 1.1 |
| **Конверсия в выдачу** | `Conversion rate` | Отношение количества фактически выданных кредитов к общему количеству поданных заявок. *Цель: 25%*. | Интервью 1.1 |

## 2. Термины оценки и риска

| Термин | EN (в коде) | Определение | Источник |
| :--- | :--- | :--- | :--- |
| **ПСК (Полная стоимость)** | `Total Cost of Credit (TCC)` | Расчетный показатель (в % годовых), включающий платежи по основному долгу, проценты и иные платежи по ст. 6 353-ФЗ. Ограничен сверху предельным значением ЦБ. | 353-ФЗ |
| **ПДН (Долговая нагрузка)** | `Debt-to-Income (DTI)` | Отношение среднемесячных платежей по всем кредитам (данные из КБКИ + запрашиваемый кредит) к среднемесячному доходу клиента. | Указание ЦБ |
| **Скоринг** | `Scoring` | Этап автоматической оценки (Decision Engine). Для MVP (действующие клиенты) включает оценку поведенческих данных (зарплата, обороты по картам). | Риски |
| **Стоп-фактор** | `Stop-factor` | Правило, при срабатывании которого заявка получает автоматический статус `Bank Reject` без дальнейших проверок. Делятся на регуляторные (самозапрет) и политические (возраст). | Риски |
| **Период охлаждения** | `Cooling-off period` | Обязательная пауза между подписанием договора и зачислением средств. Зависит от суммы: < 50 тыс. ₽ — нет; 50-200 тыс. ₽ — 4 часа; > 200 тыс. ₽ — 48 часов. | 353-ФЗ |
| **Самозапрет** | `Self-ban` | Ограничение клиента на выдачу ему кредитов. Проверяется через запрос в БКИ. Является регуляторным стоп-фактором. | 218-ФЗ |

## 3. Регуляторика (Требования к системе)

| Норма / Закон | Требование к конвейеру | Этап процесса |
| :--- | :--- | :--- |
| **115-ФЗ (ПОД/ФТ)** | Проверка ФИО клиента по Перечню экстремистов/террористов (МВК). При совпадении — заморозка заявки и алерт в Финмониторинг. | Создание заявки (на входе) |
| **218-ФЗ (Кредитные истории)** | 1. Проверка наличия согласия на запрос в БКИ.<br>2. Запрос отчета в КБКИ (вкл. проверку самозапрета).<br>3. Исходящая отправка данных в БКИ о любом решении (отказ, выдача). | Оценка заявки / Смена статусов |
| **353-ФЗ (Потреб. кредит)** | 1. Расчет ПСК и вывод его в договоре.<br>2. При ПДН > 50% — формирование экрана уведомления о рисках до подписания.<br>3. Блокировка кнопки зачисления на время периода охлаждения. | Формирование предложения / Подписание |
| **Закон о ЦБ (МПЛ)** | Учет квартальной квоты (бюджета) на выдачу кредитов заемщикам с высоким ПДН. При исчерпании лимита — отказ банка (`Bank Reject`) или снижение суммы. | Принятие решения |
| **152-ФЗ (Перс. данные)** | Наличие согласия на обработку, маскирование ФИО/паспорта в системных логах, локализация БД на территории РФ. | Весь цикл |
| **63-ФЗ (Об ЭП)** | Подписание кредитного договора простой электронной подписью (ПЭП) через SMS/Push-код на основании действующего договора ДБО. | Подписание договора |
