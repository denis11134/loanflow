# Интеграции

[Контракт учебной АБС](abs-contract.md) задаёт отправку, чтение и закрытие распоряжения для стенда. Машиночитаемый контракт находится в `api/abs.openapi.yaml`.

[4.1. Интеграционная архитектура](4.1-integration-architecture.md) показывает связи LoanFlow с другими системами и ведёт к диаграммам оценки заявки и выдачи.

[4.2. Маппинги полей](4.2-field-mappings.md) описывает контракты КБКИ, паспортной проверки, антифрода и действующей АБС.
